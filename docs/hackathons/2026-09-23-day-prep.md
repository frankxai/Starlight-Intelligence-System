# 23 September — day prep runbook (ultra-high-quality bar)

**Status:** runbook, written 2026-09-21 evening. Companion to `2026-09-23-accel-ai-innovate-amsterdam.md` (the decision and day plan) and `docs/strategy/2026-09-21-convergence-v3.md` section 12 (phone verify). Every line is a check with an owner seat and an artifact. Nothing here is a slide claim.

## 0. The bar

The judges verify the brief they watched being made, on their own phones, against a registry key, in under a minute. Every number they see is read from that receipt. If the phone path fails, the story is a slide. That is the falsifier for the whole foundation (v3 §2.10).

## 0b. Frank only, in order (everything else an agent has done or can do)

Four moves need Frank's hands or Frank's word. Each is one command or one click; the scripts were run end to end on 2026-09-22 with a throwaway key, and a rendered card's QR decoded back to the exact signed link.

| # | Move | Command or click | Why only Frank |
|---|---|---|---|
| F1 | Generate the Desk key on the demo laptop | `node protocol/sign.mjs keygen .starlight/keys` | the private key must never exist anywhere but that machine |
| F2 | Put the public half in the registry | in `starlight-intelligence-web`: `node scripts/add-trusted-key.mjs <path>/.starlight/keys/sip-signing.pub --owner "Frank Riemer"` then commit `lib/trusted-keys.ts` on a branch and open the PR (the script prints the PR body) | the registry is a list of people the site vouches for; an agent cannot vouch for a person |
| F3 | Mark PR #54 (web) and PR #189 (SIS) ready and merge them, registry PR last | GitHub | production `main` is Frank's call, never an agent's |
| F4 | Re-check Token Factory prices and the org's zero-retention setting in the Nebius console | console | login-walled; the numbers on the day must be first-hand |

The Desk itself is built: route `/desk`, engine in `site/src/lib/desk/`, 25 tests, no new dependencies. Seven stages — recall, retrieve, extract, synthesize, contradict, judge, remember — so the room sees the Desk argue with what it held last time, and the vault is one JSONL file the customer owns. See `docs/hackathons/desk.md`. It needs `NEBIUS_API_KEY`, `TAVILY_API_KEY`, optionally `SIS_SIGNING_KEY` to sign what it issues, and optionally `DESK_VAULT_PATH` to put the vault somewhere other than `site/.starlight/desk-vault.jsonl`.

After F1, every receipt on the day comes from one command: `node --experimental-strip-types scripts/receipts/issue-and-share.mts <draft.json> --key .starlight/keys/sip-signing.key --ledger` (draft shape in `scripts/receipts/examples/desk-brief.draft.json`). It signs, self-verifies, writes the envelope, the phone link and a printable A5 card with a 64 mm QR, and appends to the ledger. The link is the compact `z:` form (about 1.3k characters), so the QR on paper carries the whole signed receipt: no ledger, no network on the issuing side, and the phone verifies against the registry once F2 is merged.

- No key on the demo laptop's shared folders, no key in a chat, no key in git.
- No adjective without a file or a receipt behind it (narrative doctrine §7).
