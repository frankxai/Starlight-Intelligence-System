Standardise on a two-model cascade, not a single model: a small extractor plus one reasoning model keeps a weekly brief under three cents.

For a solo founder publishing one brief a week, the model choice is a routing decision, not a loyalty decision.

Hypothesis

An open-weight cascade on EU-hosted inference matches a closed API on rubric quality for research briefs while cutting cost per brief by an order of magnitude.[1][3]

Method

Same question, same eight Tavily sources, two pipelines. Ours: Nemotron 3 Nano extracts claims with quotes and URLs, DeepSeek V4 writes the six-section brief, GPT-OSS scores it against the research rubric. Baseline: one closed model does everything.[2][5]

Results

Extraction is mechanical work and a 3B-active model does it at a tenth of the price with structured JSON output.[1] Synthesis is judgment work and the reasoning model carries it, with citation discipline holding at 16 of 17 claims linked to a source passage.[4]

Token Factory exposes an OpenAI-compatible endpoint, so the whole cascade is provider config in the Vercel AI SDK, not custom integration.[2] Embeddings for memory recall come from the same engine.[6]

Takeaway

Standardise on the cascade shape, and let the model IDs be config strings you swap as the open-weight leaderboard moves. The founder keeps the memory as JSONL, the brief is signed, and every run prints its own cost.[3]

Next

LoRA a small Qwen3 on sixty published briefs for the format, then re-run the rubric. Publish the before-and-after as the next lab report.[5]

Conflict · memory

Prior belief in the vault, 12 Aug 2026: “keyword retrieval is enough at second-brain scale; embeddings are not worth the dependency.” This brief argues for hosted embeddings on the recall path. Which holds? Run the eval below before promoting either.
