# Starlight World

Private drive surface for the world Frank actually leads.

This is **not** Q-Town. That name was a borrowed placeholder. It is also **not** Starlight Agent Canvas. Canvas is an OSS source-intake product.

## What this is

Three layers, one driver:

| Layer | What you steer | Source of the names |
|---|---|---|
| **Palace** | Eight Mind Palace rooms | Founder lock: Lighthouse, Ocean House, Studio, Forge, Commons, Living Lab, Treasury, Observatory |
| **Vaults** | Six SIS semantic vaults | SIS memory architecture |
| **City** | Five operating districts | Starlight, FrankX, Arcanea, GenCreator, Command |

## Drive it

Open `docs/starlight-world/index.html` locally.

```bash
python scripts/validate-starlight-world.py
```

Click a room. Arrow keys move. Stewards stay `registered`. No live spawn. No private notes.
