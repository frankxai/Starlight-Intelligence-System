## 2. Excavation Methodology: The Rule of 3-5-7

Genius cannot be invented; it must be **excavated**. When you run the `/discover-genius` protocol, the system ingests raw material and applies mathematical rigor:

- **1 Occurrence = An Anecdote.** An interesting observation, but not yet an engine.
- **3 Occurrences = A Pattern.** When you tackle three completely different problems using the same heuristic or mental model, an underlying framework is emerging.
- **5 Occurrences = A Framework.** A structured, repeatable methodology with identifiable inputs, transformations, and outputs.
- **7 Occurrences = A Signature.** Your authentic intellectual fingerprint. The worldview and methodology that distinguishes your work from everyone else in the world.

### The Cross-Domain Synthesis Edge
True genius almost never exists within a single narrow silo. It thrives at the intersection of two or more distinct disciplines:
- **Systems Architecture × Sound Design:** Treating distributed microservices like polyphonic orchestral voices.
- **Neuroscience × Product Growth:** Designing user onboarding around dopamine feedback loops and cognitive load theory.
- **Cryptography × High-Touch Community:** Engineering sovereign membership economics with cryptographic guarantees.

The excavation protocol forces you to name this intersection explicitly.

## 3. The Four-Bucket Sorting Framework

Once your frameworks and mental models are cataloged, every recurring task on your calendar or backlog must be sorted into exactly one of four buckets:

```
+-------------------------------------------------------------------------------+
| BUCKET      | DEFINITION                       | DESTINATION                  |
+-------------+----------------------------------+------------------------------+
| 1. KEEP     | Work only you can do. High taste,| Retain in your personal      |
|             | 0-to-1 breakthroughs, core vision| focused daily block (2-4 hrs)|

|             | empathy, physical presence, or   | with an explicit brief       |
|             | external agency representation.  |                              |
+-------------+----------------------------------+------------------------------+
| 3. AUTOMATE | Systemic, repetitive digital     | Starlight Teammates fleet    |
|             | workflows with verifiable tests. | (Queen, GitHub Officer, etc.)|
+-------------+----------------------------------+------------------------------+
```

### Deep Dive: What Goes into AUTOMATE?
Autonomous digital workers excel when bounded by unambiguous contracts. Tasks ripe for the Starlight Teammates fleet include:
- **Morning Fleet Sweeps:** Starlight Queen reviewing open PRs, checking CI runs, and aggregating overnight market alerts.
- **Security & Lint Audits:** GitHub Officer inspecting code changes against Sentinel gates and preventing path traversal or credential leaks.
- **Lab & Literature Ingestion:** Search Manager monitoring arXiv preprints, Anthropic/Google/OpenAI release logs, and synthesizing executive digests.
- **Community Pulse Synthesis:** Community Lead extracting common user pain points from Discord or Discourse and drafting weekly FAQ cards.

## 4. Voice Fingerprinting: Defeating AI Slop

The primary reason creators resist delegating to AI is **voice corruption**. Default LLMs generate homogenised, corporate, or overly enthusiastic text filled with dead clichés (*"In today's fast-paced digital world..."*, *"delve into"*, *"unlocking synergy"*).

### The Voice Signature Extraction Protocol
A true sovereign teammate fleet must write and think using your authentic voice:
1. **Lexical Vault (15-20 Anchor Words):** The specific technical and philosophical terminology you naturally use (e.g. *substrate, sovereign, fail-closed, compounding, tactile, telemetry*).
2. **Taboo Vocabulary (Banned Words):** Explicitly blacklisting generic filler words, corporate jargon, and overused AI transition tropes.
3. **Sentence Cadence & Rhythm:** Calibrating the mix of short, staccato punchlines and deep, explanatory prose.
4. **Attitudinal Stance:** Defining your perspective (e.g., *direct, technical, warm, playful, high intellect, purpose-driven*).

When this voice model is anchored in the **Creative Vault (✦)**, every outgoing PR draft, newsletter section, and teammate communication reads as if it were penned by you at your sharpest.

## 5. The Freedom Path Progression

Transitioning from overwhelmed operator to sovereign commander follows a three-stage lifecycle:

```
Level 1: Solo Operator (0% Autonomy)
  - You write all the code, run all commands, fix all typos, manage all servers.
  - Cognitive load: 100%. Headspace for new vision: 0%.

Level 2: AI Pair Programmer (30% Autonomy)
  - You use conversational chat assistants to draft functions and summarize text.
  - Still require constant supervision and context re-prompting.

Level 3: Sovereign Fleet Commander (80%+ Autonomy)
  - Autonomous Teammates run in microVMs hydrated by your 6 memory vaults.
  - Teammates execute tasks in background, respect fail-closed governance,
    and only surface Approval Cards for high-stakes decisions (finances, main merges).
  - You spend 80% of your time in your KEEP bucket (deep creative genius).
```
