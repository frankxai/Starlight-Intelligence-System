Rule 1 · thinking on open weights

Every hop that reasons, extracts, judges or embeds runs on Token Factory or a swappable open model. Closed generators render behind adapters from a signed brief.

Rule 2 · one memory, four graphs

JSONL vaults are truth. Indexes are rebuildable. Supabase holds shared runtime state. No graph per agent, no hosted vector DB as a second source of truth.

Rule 3 · humans hold the irreversible

Publish, pay, merge to main, rotate keys. Agents draft, route, prove and propose. The approval receipt is signed with the usage receipt.

Rule 4 · every surface is a projection

Sites, PWA, desktop cockpit and MCP clients all read the same vault, ledger and receipts. No surface owns state the others cannot see.

Rule 5 · nothing pre-cached masquerades as live

The Console's rule for the whole estate. A demo shows what ran. Illustrative numbers are labelled until they are real.

Rule 6 · the file contract is the harness

AGENTS.md, SOUL.md, SKILL.md and receipts travel across Claude Code, Codex, Grok Build, Antigravity and Kimi. Frameworks stay thin and replaceable.
