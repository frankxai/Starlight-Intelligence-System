## 2. Vault Durability Tiers: From Local to Blockchain Permanence

Memory loss is the existential risk of modern AI agent workflows. SIS provides three progressive durability guarantees:

### Tier 1: Sovereign Local (Free / Open-Core)
- **Engine:** SQLite FTS5 hybrid index backed by append-only JSONL event logs.
- **Dependency:** Zero external network connection required.
- **Guarantee:** Complete data sovereignty on user hardware. Full P2P sync capability via Syncthing.

### Tier 2: Managed Cloud Durability (Subscription Tier)
- **Engine:** Automated multi-region snapshot encryption and replication.
- **Features:** Instant device restore, conflict-free CRDT synchronization, and session handoff across desktop, mobile, and cloud runner environments.

### Tier 3: Blockchain-Anchored Permanence ("Never Lose This")
- **Engine:** Decentralized immutable storage (Arweave / IPFS / Filecoin) paired with smart-contract cryptographic state anchoring.
- **Mechanism:**
  1. Horizon Vault letters and critical strategic decisions are compiled into deterministic Merkle DAGs.
  2. The snapshot Merkle root is anchored onto a public blockchain ledger.
  3. Every archive record carries a cryptographically verifiable Content Identifier (CID) and transaction receipt.
- **Outcome:** The intelligence system's core values, memory, and architectural decisions survive cloud vendor deprecation, infrastructure insolvency, or platform deplatforming.

## 4. The Thin Overlay Strategy: Composable Leverage

A key design doctrine of SIS is **"Thin Overlay Everywhere"**:
- **Observability:** Thin adapter into **Langfuse** (EU self-hosted or cloud) for LLM tracing, evals, and cost attribution, rather than maintaining a proprietary metrics dashboard.
- **Model Routing:** Thin adapter into **OpenRouter** and native provider SDKs for resilient model fallbacks (Claude 3.7/3.5, Gemini 2.5/3.0, GPT-5, Grok).
- **Deployment Surfaces:** Vercel and Cloudflare for high-speed edge delivery.
- **No Heavy Monoliths:** We own the cognitive protocol, memory contract, and governance kernel; we plug into best-in-class infrastructure.
