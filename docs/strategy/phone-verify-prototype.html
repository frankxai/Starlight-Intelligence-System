What happened, in under a minute

3s

Scan

The camera reads the QR. The URL carries only the receipt id, never the payload, so the QR stays small enough to print at 28 mm.

0.4s

Fetch

The verifier reads the envelope from the public ledger entry the issuer chose to publish. Unpublished receipts cannot be fetched; they verify by paste.

14ms

Verify

Ed25519 over the DSSE pre-authentication encoding, the in-toto statement check, and the receipt's own arithmetic. Same code as the API and the MCP tool.
