# durable-lease-owner

Status: proposed

## Context

A disconnected local executor can finish after a replacement starts. In-memory ownership cannot survive isolate eviction.

## Options

- Existing SwarmCoordinator with durable fenced leases
- In-memory map and best-effort TTL
- Independent central scheduler service

## Decision

Existing SwarmCoordinator with durable fenced leases

## Consequences

Persist state, operation identity and generation atomically. Gate every artifact-acceptance/effect sink against the current fence; issuing a fence alone cannot prevent stale external writes. Keep protected HTTP contained until verified authority is integrated.

## Revisit

Adversarial race or restart test breaks exclusivity, or measured workload exceeds one-object scope.

Evidence: cloudflare-storage
