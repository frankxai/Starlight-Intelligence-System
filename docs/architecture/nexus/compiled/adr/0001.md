# nexus-boundary

Status: proposed

## Context

The older Nexus draft mixes catalogue, graph and authority concerns. The current mission product and SIS already own useful boundaries.

## Options

- Existing SIS execution fabric with existing product UI
- Separate Nexus platform/repository
- Read-only discovery catalogue

## Decision

Existing SIS execution fabric with existing product UI

## Consequences

Nexus names this module. Starlight Intelligence Network describes the federation, without creating another brand, ledger, protocol authority or control plane. This revises draft #476; it is not ratified Registry policy.

## Revisit

A distinct release, audience or permissions boundary is proved and admitted through the Registry.

Evidence: registry
