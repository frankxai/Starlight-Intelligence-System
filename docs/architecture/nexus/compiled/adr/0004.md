# private-checkpoint-storage-exception

Status: proposed

## Context

Cloud-oriented executors need immutable private checkpoint bytes. Accepted architecture_media_fabric_v2 still governs web media.

## Options

- Proposed R2 exception for private non-web checkpoints
- Existing Vercel Blob for all checkpoint bytes
- Owner-local checkpoint only

## Decision

Proposed R2 exception for private non-web checkpoints

## Consequences

Proposed exception only: non-Vercel execution access and restore are the workload need. SIS owns checkpoint schema; application metadata owns authorization and retention. Admit no new bucket until review, region/retention validation and cost comparison. Start with new checkpoints only; retain legacy references. Roll back adapter selection to owner-local/approved Blob; verify hashes, drain references and remove replicas only after retention obligations. One authoritative object per checkpoint version; optional recovery copies record lineage and expire under policy. No web-media migration.

## Revisit

Measured cost, security or restore evidence fails the chosen adapter, or the Registry declines the exception.

Evidence: registry
