# placement-and-continuation

Status: proposed

## Context

A mission can resume on another executor only when its inputs, grants and data boundary permit it.

## Options

- Explicit outbound node pull with checkpoint handoff
- Public inbound local control port
- Unconditional cloud failover

## Decision

Explicit outbound node pull with checkpoint handoff

## Consequences

Use time-bounded leases and source/artifact digests. Transfer explicit task checkpoints, not process memory or entire private machine state. Tunnel is optional connectivity for selected services and never execution authority.

## Revisit

A workload requires interactive inbound service access with a separately reviewed Access policy.

Evidence: registry
