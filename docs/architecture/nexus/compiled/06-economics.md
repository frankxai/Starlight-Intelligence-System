# Commercial and capital contract

Treat offer/prices as experiments. Free: portable project pack, contracts and export. Paid candidates: maintained implementation, evaluated practice, managed operation and team controls. Validate willingness to pay and second useful use before adding recurring overhead.

Separate customer allowance from supplier cost and consumer subscriptions. One merchant/entitlement authority per SKU. Quote → atomic reserve → admit → execute → reconcile → settle once → release unused balance. Gateway limits are not a customer-credit ledger. Reuse existing admission and settlement contracts.

Run `architect.py economics scenario.json` with integer monetary minor units and one explicit currency. Include failed work, reviews, tools, support, fees and refunds. Unknown costs are not zero. Reinvest only cleared contribution after reserve and obligations; no purchase follows from this document.
