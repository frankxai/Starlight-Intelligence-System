# Nexus: mission continuity across approved machines

Project projection · proposed · 2026-10-31

| Field | Decision/input |
| --- | --- |
| beneficiary | Technical founders and small product teams operating an existing repository across local coding harnesses and cloud execution. |
| job | Keep one bounded repository mission coherent while people, harnesses and approved execution machines change. |
| accepted_outcome | A repository change with exact-source tests, a reviewable PR, artifact lineage and measured usage; an interrupted executor cannot submit an authoritative stale result. This is the target journey, not a claim of hosted availability. |
| commercial_hypothesis | Keep portable contracts, local operation, reproducible examples and BYOK export in the existing MIT open core. Test a fixed workspace subscription for managed coordination, team controls and recovery, with compute funded separately. Price, margin and willingness to pay remain unapproved and unmeasured. Expand only after the proposed five-team pilot clears its repeat-use, comparative-quality and paid-renewal gates. |
| first_slice | Implement internal durable fenced lease arbitration at the existing services/starlight-cloud-worker SwarmCoordinator boundary: tenant/resource binding, operation idempotency, acquire/renew/release, generation fencing and restart recovery. Preserve HTTP 503 containment until identity, membership and admission are qualified. Exact implementation and test results belong in the parent release receipt. |
| next_action | Qualify the internal arbiter with independent review, then integrate verified node identity and current-request admission before an isolated local-to-cloud handoff rehearsal. Compare the same frozen repository missions against manual handoff and an assembled existing coding harness plus persistent cloud workspace plus GitHub PR workflow. After hosted and commercial qualification, test five teams; stop breadth expansion and repair the workflow if the proposed pilot gates are missed. No customer dispatch, pricing or cloud deployment is authorized by this projection. |
