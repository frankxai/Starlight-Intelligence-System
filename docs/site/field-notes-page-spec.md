# Field Notes Page Spec — Protocol and Public Memory

- Route: `/field-notes` within `site/`.
- First read: proof stays close to the humans who hold authority and to the public memory that survives the run.
- Audience: protocol implementers, operators, collaborators, and public-source evaluators.
- Asset tier: Tier B custom generated institutional editorial media.
- Visual world: large-format civic documentary; obsidian, mineral, restrained violet, brass, human-scale light.
- Composition: editorial hero plus public proof contract, three-principle strip, two chapters (3 + 3 cards), complete constellation links, proof disclosure.
- Motion: dynamic GSAP import near the field; maximum three cards per reveal; subtle pointer tilt, image amplification, local glow, sparse stars, and one attestation-like trace.
- Static contract: server-rendered route remains complete; mobile, coarse pointer, reduced motion, and failed JavaScript do not depend on GSAP.
- Performance budget: six 1120 × 1400 WebP images below 240 KB each; no new runtime dependency, ScrollTrigger, pinning, WebGL, or DOM particles.
- Accessibility: meaningful alt text, human-readable disclosure, keyboard-accessible links, no information exclusively on hover.
- Proof boundary: generated images are never deployment, governance, customer, or participant evidence.
