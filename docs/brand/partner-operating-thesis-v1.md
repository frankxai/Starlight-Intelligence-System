# Starlight partner and investor operating thesis · v1

**As of 2026-09-23.** This is an operating hypothesis for conversation, not a traction deck. Status derives from `origin/main` at `a54cc7090f53ebe4f79765ba01e6a459d835b2dd` and the [claim map](claim-evidence-2026-09-23.md). **Fact** means observable in the reference repository; **hypothesis** requires a test; **horizon** is long-term intent. [Issue #197](https://github.com/frankxai/Starlight-Intelligence-System/issues/197).

| Element | Thesis and evidence boundary |
| --- | --- |
| **Category** | **Decision:** Local-first intelligence infrastructure for owner-directed venture portfolios. The reference build has local working memory and verification tools, with partial Foundry packaging; the integrated portfolio product is in progress. [Decision memo](next-era-decision-v1.md); [claim map](claim-evidence-2026-09-23.md). |
| **Problem** | **Hypothesis:** Valuable decisions, context, and operating methods are lost between conversations, tools, teams, and projects. Ventures then spend time recreating capability that already exists. No loss rate or market size is asserted. [Issue #197](https://github.com/frankxai/Starlight-Intelligence-System/issues/197). |
| **Wedge** | **Fact:** The repository contains executable local memory, partial Foundry capability packaging, SIP conformance and receipt tools, and an authenticated Command Center model. **Decision:** Start with teams willing to inspect source and operate a local reference build; do not sell autonomous venture operation as the wedge. [Claim map](claim-evidence-2026-09-23.md). |
| **Product** | **Decision:** Command, Memory, Teams, Capabilities, Operations, Transfer, and Evidence are visitor-facing groups over existing code, not a replacement for the locked ten-system substrate taxonomy. Network is research; Academy is a learning/distribution direction. [Narrative canon](narrative-canon-v1.md); [STACK.md](../../STACK.md). |
| **Compounding loop** | **Hypothesis:** Create → Capture → Verify → Transfer → Operate → Learn. A qualifying transfer records source venture, destination venture, capability version, permission, verification receipt, baseline, result, and attribution caveat. Current main has no complete qualifying cross-venture outcome record; the baseline is **unmeasured**. [Claim map](claim-evidence-2026-09-23.md). |
| **Portfolio model** | **Decision:** Ventures own their products, decisions, identity, and domain assets. Shared infrastructure can carry proven methods between them when permitted. Their ability to export or fork independently is a product test, not an assumed guarantee. [Constitution](../../site/src/app/constitution/page.tsx); [decision memo](next-era-decision-v1.md). |
| **Potential moat** | **Hypothesis:** As distinct ventures operate, they may produce reusable capabilities and evidence that reduce reinvention for later ventures. This advantage exists only if a later venture improves against a credible baseline and the reused capability plausibly caused part of that improvement. A repository count, agent count, or copied prompt does not establish it. [Claim map](claim-evidence-2026-09-23.md). |
| **Distribution** | **Fact:** The code and public site offer a developer path; the creator path defines a no-terminal publication and attestation flow. **Hypothesis:** Public proof, developer adoption, founder/operator use, creator artifacts, and later Academy learning could bring qualified operators into the system. No conversion or partnership number is claimed. [Creator path](../../skills/integration/creator-path.md); [claim map](claim-evidence-2026-09-23.md). |
| **Current evidence** | **Fact:** Local memory, passing Foundry skill-package paths, SIP conformance/receipt verification, and work models have source and tests. **Limit:** Foundry's OpenAI plugin projection fails audited-main preflight; Command Center deployment, verified transfer, external interoperability, and economic outcomes need proof. Seed workspace revenue and illustrative proof UI are excluded. [Claim map](claim-evidence-2026-09-23.md). |
| **Economics** | **Hypothesis:** Reuse may reduce idea-to-working-product time, new-operator time-to-context, duplicated work, or quality failures. Potential value capture could come from operating infrastructure or services built on proven patterns; pricing, margin, retention, and venture-level attribution remain untested. No TAM, forecast, revenue, or customer figure is asserted. [Strategic vault, historical model](../../memory/vaults/strategic-vault.md); [decision memo](next-era-decision-v1.md). |
| **Milestones, next 12–24 months** | **Proposed gates:** (1) working, reproducible Command-to-evidence path; (2) one permissioned transfer between two ventures with a signed/source-linked record; (3) matched baseline and outcome for the transferred capability; (4) repeat the test with another capability or venture; (5) demonstrate venture export/fork independence; (6) publish a privacy-safe Notes export and revision record. Dates are targets for sequencing, not delivery promises. [Claim map](claim-evidence-2026-09-23.md); [Board pre-pass](../boards/2026-09-23-next-era-public-narrative-prepass.md). |
| **North star** | **Hypothesis to instrument:** Verified capability reuse that improves a real venture outcome. Record numerator and denominator, baseline method, outcome, permission, and attribution uncertainty. Supporting measures: time-to-context, decision recall, inherited-context versus cold-start success, duplicate-work rate, and public claims backed by executable evidence. [Claim map](claim-evidence-2026-09-23.md). |
| **Falsifiers** | **Decision:** Revise the thesis if permissioned transfers repeatedly fail to improve later-venture outcomes, if a venture cannot leave with usable knowledge and capability, if proof collection costs more than the benefit it creates, or if governance/privacy boundaries fail. Demote any public claim whose evidence fails. [Decision memo](next-era-decision-v1.md); [SIP](../../SIP.md). |
| **Long horizon** | **Horizon:** Knowledge and useful operating capability survive changing software, teams, and institutions, potentially helping more capable and caring human futures. This is the mission frame; autonomous ventures, federation, and civilizational results are not current traction. [Horizon vault](../../memory/vaults/horizon-vault.md); [claim map](claim-evidence-2026-09-23.md). |

**Decision for a serious partner:** Start with a bounded capability, a named owner, a privacy boundary, and an agreed baseline. Run the local tools, inspect the receipt, test one transfer, and decide from the measured result. [Command Center skill](../../plugins/starlight-intelligence/skills/starlight-command-center/SKILL.md); [claim map](claim-evidence-2026-09-23.md).
