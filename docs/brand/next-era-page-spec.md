# Next Era public spine · page and scene brief

Version 1 · issue #197 · 2026-09-23. Source boundary: `docs/brand/claim-evidence-2026-09-23.md`; Board: `docs/boards/2026-09-23-next-era-public-narrative-prepass.md`.

## Outcome

Audience: a founder, capable developer, creator, or serious partner arriving without Starlight vocabulary. Within one minute they should know the category, working local primitives, unfinished transfer promise, venture independence, and where to verify or try the code.

First read: “Intelligence should compound” anchored immediately by “local-first infrastructure for owner-directed venture portfolios.” Primary action: See the evidence. Evidence in the first viewport: direct links to the local memory code, receipt verifier, and capability proof code; no invented dashboard state.

## Design-coherence derivation

Voice: direct, technical, warm (`CLAUDE.md`) with founder-specific systems/composition patterns (`genius/profile-frankx.md`), without publishing personal source material. Mood: precise, spacious, humane. Anti-mood: theatrical. The brand foundation reset of 2026-08-17 is active; the current site mark and typography are preserved while this PR develops an editorial/product layer, not a replacement identity.

Two modes share typography, spacing, mark, and a single accent system. **Evidence Mode** uses light reading surfaces, dark ink, exact source paths, and no decorative metric chips. **Horizon Mode** uses a dark, quiet field and large editorial type for the origin and future story. The switch is about content density, not two separate brands.

Existing site fonts: Inter for interface, Newsreader for editorial voice, JetBrains Mono for code. The curated matrix lists Manrope/IBM Plex Mono for operations, but introducing a new font stack before identity review would expand this change. No new logo or celestial wallpaper is introduced.

## Scene order

1. Category and proof hooks: clear product statement and one action.
2. Lost intelligence: concrete failure of context, decisions, and repeated work.
3. Operating mechanism: Create → Capture → Verify → Transfer → Operate → Learn, with incomplete transfer labeled.
4. What works today: source-linked, dated local capabilities. No seeded traction.
5. Compounding requirement: a verified transfer record needs source, destination, receipt, baseline, and outcome.
6. Independent ventures: Starlight / FrankX / Arcanea / Notes relationship and sovereignty.
7. Sovereign architecture: exportable files, local tools, signed receipts; distinction between declaration and proof.
8. Long horizon: generation-scale purpose labeled aspiration.
9. One action: `/proof`, with quickstart one step away.

`/story` houses origin and seven reusable exact-text narrative artifacts. `/proof` maps product claims to code and tests. `/notes` is a curated public archive model and must never import private vault files. Existing `/architecture`, `/constitution`, `/quickstart`, `/protocol`, and `/vaults` remain the deeper sources.

## Seven-artifact composition

Source: seven independent content modules using semantic HTML and CSS, not baked image text. Each has a web-section composition plus aspect-preserving 16:9, 4:5, and 1:1 export modes. Exact SVG vector export is the high-resolution format; type remains selectable and SVG title/description convey the message. Diagrammatic artifacts use Tier C because exact relationships are the subject. The manifesto and origin include the existing brand mark or a real source object; no generated media or third-party images are needed.

## Motion and interaction

Static composition first. Use only short CSS transitions for links and export controls; no scroll trap, ambient animation, or canvas. Focus is visible, links are at least 44px high, hover is limited to fine pointers, and reduced motion removes transforms. Export selection can be interrupted without leaving stale visual state.

## Acceptance

- Build, type, lint, and route checks pass.
- Desktop and mobile first viewport; seven export ratios; keyboard focus; touch; reduced motion are inspected.
- Every public LIVE claim has a direct source/test/receipt path; no seed/demo metric reads as traction.
- Visual QA reaches at least 26/30, with screenshot evidence and an evidence manifest.
- A separate Sentinel and Codex adversary pass checks the actual diff before PR readiness.
