**Privacy boundary:** private repositories, the operator's personal and financial systems, family relationships, health records, ChatGPT conversations, credentials and unpublished partner information are **deliberately excluded**. Public evidence must not link to or enumerate private estate state. A private owner inventory belongs in an access-controlled operator location with scoped write and promotion gates.

## Readiness semantics

Use precise, independently checkable stages for each repository or capability:

1. **Observed** — repo/path found at a dated source; no run evidence.
2. **Inspected** — source/owner/architecture reviewed at an exact commit.
3. **Locally tested** — reproducible tests and dependency/runtime matrix linked.
4. **Integration tested** — scoped auth, revoked credentials, recovery and negative paths exercised.
5. **Hosted verified** — exact preview/production deployment, user journey, telemetry and receipt verified.
6. **Commercially verified** — actual entitlements, invoices/merchant eligibility or users evidenced; otherwise *unknown*.

Never convert the repository `active` label, agent definitions, a passing local fixture or an open PR into a production claim. Preserve `unknown` explicitly.
