## Critical Context

### Architecture decisions

1. **`private/voice-operator/` is gitignored.** All operational code (5,800+ LOC) lives there. CI in `.github/workflows/voice-operator-tests.yml` only validates the substrate-clean public-side artifacts (agent file, skill file, registry entries). Operational tests run locally via `pytest tests/`.

2. **Substrate-tier governance gate (v7.5.1+).** Any change to `SIP.md` / `SIS.md` / `STACK.md` / `VERTICALS.md` / `VOICES.md` / file-contract / attestation rules / sovereignty / 10-IS taxonomy invokes `/luminor-board` BEFORE commit/tag, not after. Voice Operator was board-cleared on 2026-04-26 morning. **Operational-tier work continues without pre-board.**

3. **Voice Operator is in Front-Door Tier**, not its own "Cockpit Tier" — board correction. It's a sibling to Concierge and Envoy. Concierge owns first-contact intake; Voice owns sessioned cockpit. Envoy owns creator-track artifacts.

4. **Handoff packet is the load-bearing artifact** — frozen v1 schema with append-only invariant, sentence-count validator on `spoken_update_for_user`, target-system ambiguity rejection. The packet is what lets voice / text / `/intake` / council fan-out all hand to the same deep agents identically.

5. **Two-direction MCP integration.** Voice Operator dispatches outward to MCP servers (Linear, GitHub, etc.) AND runs AS an MCP server so other agents (Claude Code, Codex, Gemini) can call its tools.

6. **Rate guards check_packet runs BEFORE every API call.** Daily caps (500 calls / $50 USD / 100 packets/hour) protect against runaway loops. Override via `.env` (`GUARD_DAILY_USD_CAP=...`).

7. **Knowledge graph auto-indexes every text-mode turn.** Brand auto-detected via regex (frankx / arcanea / sis / libraryos / acos / music / visuals). Best-effort; never blocks the turn.
