# Direction 01 — Proof Loom

**Thesis:** Make the proof path, authority boundary, and claim state visible in one deterministic instrument.

- **Composition:** two explicitly separate chambers for Competency and Execution, a compact truth legend, a directed SVG stage, and a source inspector. The main capability chain stays linear; plugin and opportunity remain semantic branches.
- **Type:** Newsreader for the proposition and selected object; Inter for teaching copy; JetBrains Mono for URNs, claim state, lifecycle, retries, and scopes.
- **Imagery:** coded SVG shapes only. Node shape and label redundantly encode kind; violet and cyan carry structure, amber is reserved for human authority, and dotted geometry means hypothetical.
- **Interaction:** select a node to trace its connected lineage; switch chambers without merging records; run the deterministic Mission Zero preview until it stops at the human gate.
- **Motion:** one signature trace moves evidence through the four execution stages. All other transitions are short focus changes and become immediate under reduced motion.
- **Responsive:** desktop uses rail / stage / inspector; mobile becomes a vertical proof spine with the complete semantic record below the visual.

**Product strength:** strongest operator comprehension and strongest fit with the Academy contracts.
