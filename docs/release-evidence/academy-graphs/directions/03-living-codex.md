# Direction 03 — Living Codex

**Thesis:** Teach graph engineering as an illuminated technical publication whose diagram grows chapter by chapter.

- **Composition:** long-form twelve-column editorial chapters with a sticky SVG fragment, running index, marginal provenance, and a separate human-gate interlude.
- **Type:** oversized Newsreader chapter openings, generous Inter reading measure, and JetBrains Mono source notes.
- **Imagery:** inline diagrams, doctrine hairlines, vellum grain, and a blind-embossed Starlight mark; no 3D or raster dependency.
- **Interaction:** scroll activates one proof stage, source notes expand in place, and the sequential baseline overlays as a ghost manuscript.
- **Motion:** scroll-conducted line growth only; reduced motion renders the complete chapter diagram immediately.
- **Responsive:** editorial split on desktop, single reading stream with sticky proof spine on mobile.

**Rejection reason:** excellent public teaching form, but slower for the user who needs to inspect authority, retries, provenance, and a precise execution topology as one instrument.
