# Scene brief — graph atlas

## Static composition

A restrained editorial page opens with the user outcome and a narrow reference-architecture note. A runnable quickstart replaces private operating metrics. Below, a technical drafting table holds the graph: a pale ruled field, navy paths and a red selected-state marker. The inspector exposes incoming and outgoing contracts as navigable text.

## Motion score

1. On initial load, no cinematic entrance. Content is immediately legible.
2. Switching projections replaces content immediately; edge opacity has a brief transition.
3. Selecting a node moves one red selection bracket and updates the inspector.
4. Domain route selection increases path weight and dims unrelated nodes; it never animates particles.
5. Reduced motion makes all state changes immediate.

## Responsive behavior

- Desktop: graph 2/3, inspector 1/3.
- Tablet: graph above inspector.
- Mobile: controls wrap, the graph fits the available width with optional enlargement, a native node selector provides a text-first path, and the inspector follows immediately.

## Asset decision

Tier C exact UI/vector system asset. No generated imagery is required. Provenance comes from the authored machine-readable graph model; private estate snapshots are excluded.
