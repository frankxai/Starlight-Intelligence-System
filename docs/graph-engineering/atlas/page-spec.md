# Page spec — `/graph-atlas`

## Job

Give Frank and future operators one truthful, navigable answer to: what exists, how work flows, where context comes from, what must be built next, and how Starlight wins.

## Audience

- Founder/operator deciding where to invest attention.
- Architect aligning Claude, Codex, Hermes, Antigravity, Gemini, and future runtimes.
- Creator or developer evaluating whether Starlight is an operating system rather than an agent directory.

## Required content hierarchy

1. Clear user outcome and runnable community quickstart; no private census.
2. Interactive graph projection with deterministic layout.
3. Selected-node contract inspector and domain route filters.
4. Control laws labelled as requirements, with enforcement boundaries stated.
5. Effort/token economics.
6. Primary-source benchmark.
7. Four-phase delivery roadmap.

## Visual territory

SIS Civic Intelligence foundation reset: warm paper, near-black/navy ink, documentary proof, oxidized red intervention, safety yellow sparingly, fine provenance rules. The graph is a functional Tier C system diagram, not decorative node art. No purple/cyan AI glow, glass cards, generic gradients, orbit motif, or all-caps UI.

## Interaction

- View selector swaps seven projections without changing the source model; arrow keys navigate tabs.
- Domain route selector highlights the canonical estate path and exposes its check contract.
- Nodes are keyboard-focusable buttons. Selecting one updates the inspector.
- Reference/partial/target state uses labels and line styles, not color alone; none implies live runtime health.
- Reduced motion disables the small edge-draw and inspector transitions.

## Performance and accessibility

- Server-render the title, census, and long-form sections.
- Hydrate only the graph workspace.
- Use inline SVG with deterministic coordinates; no force simulation or WebGL.
- Maintain visible focus, semantic headings, button names, text alternatives, and high contrast.
- Mobile fits the diagram with optional enlargement, a native node selector and a stacked contract inspector; no information depends on hover.

## Evidence

- `estate-graph.v1.json` validates.
- generated site data matches the authored model and excludes private snapshots.
- work-graph tests pass.
- production site build passes.
- desktop and mobile exports are inspected and scored.

## Community comparison bar

The buyer is a developer who already has an agent harness and needs a checkable workflow without deploying another service. Reference products: Langfuse agent graphs (trace inspection), LangGraph (workflow durability), and Google ADK (typed workflow composition). This kit targets lower setup friction for local instruction/graph inspection, not feature parity or superior runtime performance. No superiority claim is established until cold-start and visual review receipts exist. Primary sources are linked in `RESEARCH_2026.md`.
