Accessibility • Performance • Provenance

Accessibility
  • Full prefers-reduced-motion support (disables canvas animation, parallax, most transitions; particles drop to 28 static points)
  • ARIA roles, live regions on phase progress, keyboard-accessible nav and canvas controls
  • Semantic headings, focus-visible states, proper contrast
  • All images have precise descriptive alt text grounded in the actual system
Performance
  • Canvas swarm: 220 particles max. RAF loop. Passive scroll listeners. Throttled velocity calculation.
  • IntersectionObserver for all reveals and phase detection (rootMargin tuned for scroll storytelling)
  • CSS will-change only where needed. Canvas pauses when offscreen.
  • ~60fps on modern hardware. Graceful on lower power (reduced particle count + simpler connections when velocity high).
  • Images use native loading. No external runtime beyond Tailwind CDN (for the standalone artifact).
Provenance & Integration
  • Every visual is a canonical 2026-06-12 Grok Imagine LEDGER artifact (see docs/visuals/VISUALS.md)
  • Designed to live at starlightintelligence.org/queen or embedded in research + cockpit surfaces
  • Mirrors exact Queen v0.2 phases and driver runtime. Scroll progress = loop energy
