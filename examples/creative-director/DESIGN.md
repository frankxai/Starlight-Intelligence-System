# Creative director lab direction

Existing reference screenshots were captured by GitHub run 37534807669 before UI implementation: 375, 768 and 1440 CSS pixels for each product. These are homepage references for a new additive lab, not screenshots of a previous lab.

| Product | Three directions compared | Selected | Reason |
|---|---|---|---|
| Starlight | Trace console; spatial memory palace; research notebook | Trace console | Inspectable dependency and context evidence is the operational job; 3D does not improve this first task. |
| Arcanea | Star map; manuscript desk; production map | Production map | A world rule remains close to the scene graph, while the work can be inspected and revised. The fantasy belongs in authored content. |
| GenCreator | Signature table; edition board; general node canvas | Edition board | Start with the creator's source, show editable formats and review together, and retain graph inspection without turning the product into a tool directory. |

Use current owner tokens. Arcanea: void/surface/text/teal from apps/web/lib/design-system/arcanea-tokens.css, with restrained serif display and sans controls. GenCreator: Territory B paper/ink/spot-red OKLCH values from app/globals.css; sentence case, editorial display, no HUD or glass. Starlight: operational dark neutrals, violet/cyan evidence accents per site/DESIGN.md.

No network-loaded fonts, images, providers or analytics. Use native serif/sans fallbacks for this isolated HTML lab; application-native font integration belongs to the later React surface. Fixed SVG icons are decorative. All creator text is inserted with textContent or textarea.value.

At phone width use the same graph as an ordered node list and keep inspection below it. Desktop has source/context/team, canvas and inspector. Pan/zoom/drag have keyboard and button alternatives. Reduced motion disables transitions; there are no ambient loops. Export labels identify drafts, not media or authenticated approval.

Before promotion: inspect after captures at all three widths, supported theme treatment, keyboard/focus, long inputs, negative budgets, stale draft edits, save/restore and export. No visual score or production verdict is supplied before evidence.
