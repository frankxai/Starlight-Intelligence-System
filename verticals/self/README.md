## What Self IS does

Self IS is the foundation. Every downstream IS reads from it. Vision asks what North Star serves this genius. Business asks what entity must protect it. Creator asks which frameworks to systematize. Second Brain asks what to capture. Skip the root and the tree grows crooked.

The IS owns:
- **Genius excavation.** What only this person uniquely sees — the synthesis that emerges from the intersection of their disciplines, lived experience, and pattern recognition.
- **Freedom Path mapping.** KEEP / DELEGATE / AUTOMATE / KILL bucket allocation across the person's current operating surface.
- **Executor playbooks.** Generating handover SOPs in the person's voice for the DELEGATE bucket.
- **Reclamation organization.** Organizing scattered professional material by function-not-source.
- **Voice samples.** The Genius Profile's voice samples drive every human-facing artifact across every other IS.

## Primary commands

- **`/discover-genius`** — excavate genius from a person's scattered corpus. Produces Genius Profile + Freedom Path.
- **`/reclaim-knowledge`** — organize scattered material by function-not-source.
- **`/train-executor`** — generate executor onboarding playbook in the person's voice.
- **`/creator-pipeline`** — multi-modal content pipeline from frameworks.
- **`/content-systemize`** — convert content pillar into reusable production templates.

Vault namespace: `genius/profile-<slug>.md` · `genius/freedom-path-<slug>.md` · `genius/reclamation-map-<slug>.md`.

## Refusal patterns

- Generating Genius Profile content from generic creator templates rather than excavating from the person's actual corpus.
- Naming a "synthesis edge" the person did not declare or live (manufactured authority).
- Retaining instance Profile content in public substrate vaults — Self IS instance state stays in the practitioner's private fork.
- Treating Genius Profile as a static identity claim rather than a living document that updates as the person evolves.
