## Candidate 1 — **Razor**

### 6-axis scorecard

| Axis | Score | Note |
|---|---|---|
| Memorability | 3/3 | Single-syllable; sharp; iconic; phonetically distinct |
| Searchability | 1/3 | High existing-artist conflict ("Razor" used by multiple metal/rock bands historically; "DJ Razor"; "Razor (rapper)"). Persona will need disambiguator OR niche differentiation |
| Sonic feel | 3/3 | Sharp, distorted, aggressive phonemes — natively fits punk/alt/cathartic |
| Brand-extensibility | 3/3 | Extends to merch (sharp aesthetic), collabs, sub-projects easily |
| Canon-fit | 3/3 | Native Nona canon; brutalist + raw + anti-corporate |
| Pronounce-ability + global | 3/3 | "RAY-zur" universally stable |

**Score: 16/18**

### Pattern lineage
Pattern 1 (single-evocative-raw). Adjacent to single-name punk/alt heritage (Slipknot, KMFDM single-element naming).

### Strengths
- Sonically perfect for Nona canon
- Memorable single-syllable
- Brand-extends naturally

### Risks
- **Searchability cliff:** "Razor" is heavily used in music. Will require disambiguator like "Razor (Nona)" on Spotify or stylized variant ("RAZ0R", "Razzor") — both compromise memorability
- Trademark conflict probability moderate-to-high

### Availability check tasks
- Spotify search "Razor" — likely returns 5-20+ artists
- Apple Music: same
- USPTO/EUIPO trademark Class 9 (sound recordings) + Class 41 (entertainment): likely conflicts
- Disambiguator decision: decide before lock
