## Candidate 1 — **Lumen**

### 6-axis scorecard

| Axis | Score | Note |
|---|---|---|
| Memorability | 3/3 | Single-word evocative; light-archetype; rhythm-clean |
| Searchability | 2/3 | Some artist conflict (small acts named Lumen exist); persona can compete in lo-fi-evening niche |
| Sonic feel | 3/3 | "Lumen" — soft, warm, light-evocative phonemes — natively fits lo-fi-evening + chill-house |
| Brand-extensibility | 3/3 | Extends to merch ("luminous"), collabs (Lumen × Aurora?), sub-projects |
| Canon-fit | 3/3 | Composes with Frank's Lumina track + Lumina meditation streak (project memory ref) without overlapping; "Lumen" as standalone single-word distinct from "Lumina" |
| Pronounce-ability + global | 3/3 | "LOO-men" universally stable |

**Score: 17/18**

### Pattern lineage
Pattern 1 (single-evocative). Adjacent to existing successful single-name evocative artists (Madonna, Lorde, Halsey). Phoneme distinct.

### Strengths
- Light-archetype is universally accessible
- Composes with Frank's existing Lumina ecosystem (track + meditation streak) without trademark conflict
- Easy mental mnemonic for fans

### Risks
- "Lumen" as Spotify search returns several minor artists; need direct check before lock
- Slight risk of confusion with "Lumina" (existing track name) — but distinct enough

### Availability check tasks
- Spotify: search "Lumen" — confirm no major artist conflict
- Apple Music: same
- YouTube: same
- Bandcamp: confirm `lumen.bandcamp.com` or `lumen-vibes.bandcamp.com` available
- USPTO/EUIPO: trademark search for music-genre Class 9 + 41
