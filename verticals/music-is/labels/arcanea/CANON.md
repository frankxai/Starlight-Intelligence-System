## Sound DNA (label-wide)

### Genre + sub-genre
- **Primary:** Cinematic / orchestral hybrid
- **Sub-cohorts:**
  - Score-grade cinematic (film/TV/game placement candidate)
  - Mythic / fantasy / canon-bound
  - Trailer / epic build (high-leverage sync sub-cohort)
  - **Frequency-meditation** (per-Guardian healing-frequency tuned releases — composes with Frank's existing Ambient/Meditation/528Hz catalog)

### Reference triangle
1. **Hans Zimmer** — epic scale, modal vocabulary (Lydian / Phrygian for mythic), ostinato + build discipline
2. **Two Steps from Hell** — trailer-grade, dynamic peak architecture
3. **Ramin Djawadi** — game/TV score, character-theme discipline (each Guardian gets a theme)

### Per-Guardian frequency discipline (CANON LOCK)

Every Arcanea-label release is **tuned to the Guardian persona's Solfeggio frequency**:
- Track's master tuning (A4 reference) adjusted to render the Guardian's frequency at structurally significant pitch positions
- Drone / pedal-tone in the song corresponds to the Guardian's Hz where possible (e.g., Alera: 528 Hz drone or pedal as foundation)
- Mastering reference includes frequency-spectrum check confirming presence of Guardian's Hz

Example for Alera (528 Hz):
- Pedal tone or drone at 528 Hz
- Master tuning calibrated so the song's tonic emphasizes 528 Hz harmonics
- Composes with Frank's existing 528Hz healing-frequency cluster (FrankX MUSIC_CATALOG_INDEX.md)

This is **sonic canon**, not metaphor. Releases that don't honor the frequency canon are refused at gate.

### Harmonic vocabulary
- **Modal primary** — Lydian (mythic exalted), Phrygian (mythic darker), Dorian (heroic), Mixolydian (folk-mythic), Aeolian (introspective)
- **Per-Guardian modal preference:**
  - Alera: Lydian (exalted, healing) — natural fit for 528 Hz harmonic series
  - Draconia: Phrygian (fierce, commanding)
  - Maylinn: Dorian (heroic-heart)
  - Lyssandria: Aeolian (ancient grounding)
  - Lyria: Mixolydian (mystical-folk)
  - Aiyami: Lydian (transcendent)
  - Elara: modal mixture (synthesizing)
  - Ino: Phrygian (shadow-truth)
  - Shinkami: all modes / modulating (cosmic)
  - Leyla: Dorian/Mixolydian (flowing-wisdom)
- **Epic minor** for tension (natural/harmonic minor with brass-led peaks)
- **Pedal-tone discipline** — long bass pedals at Guardian frequency under modal motion
- **Rhythmic ostinato** as structural element

### Tempo bands
- **70-90 BPM** — contemplative mythic (Guardian solo / introspection / healing-frequency releases)
- **90-130 BPM** — heroic / journey
- **130-160 BPM** — battle / climax / Draconia + Aiyami specific
- (Free-tempo cinematic build allowed for trailer sub-cohort)

### Vocal posture
- **Choral, languageless, mythic-cadence** — primary
- **No English lyrics typically** — quasi-Latin / invented-syllables / vowel-based for mythic resonance
- **Per-Guardian vocal character:**
  - Alera: lead vocal-allowed (she IS the Voice Guardian; sung mythic-cadence)
  - Maylinn: gentle female-led ensemble
  - Draconia: powerful belted ensemble
  - Lyssandria: deep choral, ancient
  - Ino: whispered + processed shadow choral
  - Shinkami: full ensemble + cosmic effects
- **AI-cloned Frank's-voice + ensemble** allowed (disclosed)
- **Refused:** clean English-lyric pop vocals (wrong canon)

### Production posture
- **Dynamic-range protected** — score-grade mastering for sync delivery (LUFS-target ~-18 to -16 LUFS integrated)
- **Orchestral hybrid mix** — live-string-like sample libraries + synths + percussion
- **Cinematic spatial depth** — far-room reverbs, wide stereo image, height/Atmos consideration where supported
- **Per-Guardian frequency calibration** in master (see frequency discipline above)
