## Use

From repository root:

```bash
node verticals/music-is/records-os/records-control.mjs validate-registry
node --test verticals/music-is/records-os/records-control.test.mjs
node verticals/music-is/records-os/records-control.mjs check-release /private/path/packet.json
```

A successful packet check means required declarations and revision bindings are structurally present. It does **not** authenticate contracts, listen to audio, clear legal rights or authorize publication. Provider adapters must verify actual evidence and authorized scope. Keep private packets outside this public repository.

## Authority and change

Notion owns working name evidence, briefs and review notes. GitHub owns reviewed operational specifications and dated exported registry snapshots. Existing CSV records remain historical intake until reconciled; do not independently edit release truth in three systems. The future private Records API/database will own recordings, component rights, releases and actual receipts after a tested migration.

Sync is disabled. Implement field-owned upserts by stable ID with conflict quarantine and audit history. Never overwrite human decisions, legal opinions or delivery evidence from an older snapshot. `bindings.json` records the exact current surfaces and review state.
