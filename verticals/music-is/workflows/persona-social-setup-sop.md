# SOP — Per-Persona Social Setup

> Each Music IS persona maintains its own social presence across X / Instagram / TikTok / YouTube / Spotify Artist / (Bandcamp). AI-disclosure non-waivable per DECISIONS.md D11. Voice-lock per platform per persona. Frequency-capped per `amplification-mesh` skill.

**Phase activation:**
- Phase 1: Spotify Artist + Bandcamp + frankx.ai/music sub-page (when Phase 4 ships)
- Phase 3: Full social mesh (X / IG / TikTok / YT) with OpenClaws Claws
- Phase 4: Discord (per-label or per-persona depending on label canon)

## Voice-lock files per persona

Each persona has 5 voice-lock files at `verticals/music-is/labels/<label>/personas/<persona>/social/`:

- `voice-lock-x.md` — X/Twitter voice samples + banned phrases + char limits
- `voice-lock-ig.md` — Instagram voice samples
- `voice-lock-tt.md` — TikTok voice samples
- `voice-lock-yt.md` — YouTube voice samples (titles + descriptions)
- `voice-lock-sp.md` — Spotify Canvas captions + playlist pitch text

Each file contains:
- 5-10 voice samples (Frank-curated; the GOLD STANDARD per platform)
- Char/word limits
- Banned phrases (specific to platform)
- Tone register (per persona × platform combination)
- Frequency cap reminder

## Per-persona scaffold creation

When a persona spawns via `/music-persona`:

1. `persona-canon` skill creates the persona namespace
2. `social/` directory created with stub voice-lock files
3. Frank populates voice-lock samples (1-time setup per persona)
4. `naming-intelligence` skill validates social handle availability
5. Manual setup of platform profiles (Phase 0-3) → MCP-automated where possible (Phase 4+)

## Refusals (per-platform compliance)

- Setup without AI-disclosure → refuse setup; fix bio first
- Cross-persona post (one Claw account posting for multiple personas) → refuse
- Vocal-impersonation in profile content (any non-Frank cloned voice without consent) → refuse + audit
- Per-platform policy violation → refuse drop; revise content; re-submit
- Bot-engagement-fan-mimicry (mass-following, mass-liking) → refuse at architecture
