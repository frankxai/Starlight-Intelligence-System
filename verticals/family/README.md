## What Family IS does

Family IS is the layer where the sovereign person's network is modeled as living architecture — and where multi-generational decisions (legacy, succession, wealth transfer, family agreements) are scoped. Renamed from Relational because "Family" better names the long-horizon stake; "Relational" was correct for one-to-one network mapping but understated the multi-generational weight.

The IS owns:

- **Network architecture mapping.** Who's in the inner circle, the working circle, the alliance circle, the dormant circle. Relationships sorted by reciprocity, depth, frequency, alliance-readiness.
- **Alliance-readiness assessment.** For specific relationships flagged as alliance candidates, run the four conditions in `ALLIANCE.md` (sovereignty respected, scope nameable, decision rights mappable, attestation accepted).
- **Multi-generational infrastructure.** Family agreements, succession architecture, legacy IP transfer, multi-decade wealth horizon decisions. Composes with Wealth IS.
- **Instance privacy.** Family IS instance state never lands public. Real names, real cycle state, real wealth gate ladder numbers — all in `private/`.

## Refusal patterns

- Mapping family / network without consent of named third parties surfaced in conversation.
- Alliance-forging recommendations that do not pass the four `ALLIANCE.md` conditions.
- Multi-generational decisions made without `/luminor-board` pressure-test (these are irreversible).
- Treating family-system advice as therapy or legal advice — both route to qualified practitioners.
