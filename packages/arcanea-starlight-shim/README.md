# @arcanea/starlight-intelligence-system (Migrated)

> **Notice:** Starlight Intelligence System has evolved into its own sovereign protocol and foundation. This package has migrated to **`@starlight-intelligence/system`**.

## Migration Guide

Please update your `package.json` to depend on the official scoped package:

```bash
# npm
npm install @starlight-intelligence/system

# pnpm
pnpm add @starlight-intelligence/system

# yarn
yarn add @starlight-intelligence/system
```

### CLI Usage

```bash
npx @starlight-intelligence/system
```

## Backward Compatibility

This package re-exports all modules and CLI binaries from `@starlight-intelligence/system` v8.3.0+ to prevent breaking existing builds.
