# Starlight brand team starter

Turn a small set of approved brand notes into a clear brief, a LinkedIn draft and a useful editorial review. Bring your own AI account. Your editor stays in charge.

**Start with [START-HERE.md](START-HERE.md).** It contains the complete first-run prompt and fictional sources. Copy its marked prompt into a new ChatGPT or Claude conversation. No terminal, API key, connector or hosting setup is needed for that manual route. Subscription limits and model behavior remain those of your chosen app.

Five roles contribute in sequence: Director, Researcher, Strategist, Creator and Reviewer. The five roles run as sequential passes in your conversation. Nothing is published or sent.

## Included
- One portable skill with roles, a complete workflow and contained references.
- Templates for current brand context, source index, voice, memory, stable intent and exact terms.
- A fictional personal-brand example, a prepared output and acceptance prompts.
- Claude Code marketplace metadata, a portable plugin manifest and a Codex compatibility manifest.
- A dependency-free project installer and verification tests.

[INSTALL.md](INSTALL.md) covers optional coding-agent setup. [VALIDATION.md](VALIDATION.md) separates tested checks from untested behavior. [SOURCES.md](SOURCES.md) records origins and compatibility references. [examples/rehearsal.md](examples/rehearsal.md) shows a recorded fictional run.

## Boundaries
This is a portable starter. It provides no hosted agent service, persistent database, autonomous background execution, scheduling, publishing, opportunity search, booking or MCP connection. No account permissions are changed. Same-model editorial review supplies a second pass; independent verification requires another reviewer. Files do not guarantee factual or editorial quality.

Your source packet remains yours. Keep real client context in a separate private location and attach only what the client permits. Save your context and approved decisions, then supply them to future sessions. No Starlight account is required.
