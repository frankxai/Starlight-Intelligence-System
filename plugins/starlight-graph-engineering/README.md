# Starlight Graph Engineering

An open, local-first Academy Fabric plugin for turning capability claims into executable missions and defensible evidence.

## Public capability law

Knowledge, capability and portability stay free. Payment may attach to scarce compute, managed hosting, private memory, guaranteed human turnaround, institutional controls, or an accountable SLA. It may not unlock hidden curriculum, an easier rubric, stronger credential status, or ownership of learner evidence.

## Included skills

- `capability-graph-architecture`
- `mission-graph-design`
- `execution-graph-engineering`
- `evidence-graph-evaluation`
- `passport-graph-projection`
- `agent-team-composition`

## Runtime boundary

This release is skills-only. It declares no MCP server and performs no automatic graph merge, publication, credential transition, payment, installation, external messaging, or learner-data write. Persistent agent packs are compiled separately and remain inactive until their behavioral, security, and drift evidence lanes pass.

## Core graph

```text
capability -> mission -> artifact -> evaluation -> evidence -> attestation -> opportunity
```

The economic graph remains separate:

```text
principal -> mandate -> budget -> entitlement -> consumption -> receipt
```

Graph position never grants a credential, reputation, ownership, payout, or economic entitlement.

Execution topology remains a separate governed projection:

```text
objective -> typed tasks -> capability bindings -> bounded state -> recovery -> independent proof
```

A graph is justified only when a deterministic workflow, one bounded loop, or sequential skill composition cannot preserve the required parallelism, authority separation, recovery, or independent verification.

The current primary-source rationale and its evidence limits are documented in [`references/research-basis.md`](references/research-basis.md).
