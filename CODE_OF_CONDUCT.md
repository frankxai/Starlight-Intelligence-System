# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

The full canonical text is maintained at the link above. We follow it as written.

## Scope

Applies to all project spaces: repository issues, pull requests, discussions, the SIS website, and any communication channels (email, chat) where you represent the project.

## Reporting

Report conduct concerns to **conduct@starlightintelligence.org**.

For security vulnerabilities, see [SECURITY.md](./SECURITY.md) — separate channel, faster response commitment.

## Enforcement

Project maintainers handle enforcement per the Contributor Covenant guidelines linked above. Reports are kept confidential. Action may include warning, temporary ban, or permanent ban depending on severity and pattern.
