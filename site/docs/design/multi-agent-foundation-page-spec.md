# Multi-Agent Foundation Protocol — Page Spec

## Outcome contract

- Audience: technical operators and builders who need a portable, inspectable format for agent profiles, swarms, handoffs, receipts, and version evolution.
- Surface: `starlightintelligence.org/constellation/foundation` plus direct public template downloads.
- First read: a multi-agent system is a chain of declared contracts and evidence states, not a group chat with names.
- Evidence: the current 10-house / 50-agent public projection, existing capability and pack receipts, formal foundation objects, exact template files, and truthful runtime states.
- Acceptance: source-only public data, no private memory, no authority grant, accessible semantic tables/ledgers, responsive inspection, static-first, production verified.

## Protocol objects

1. Mission brief.
2. Agent profile.
3. Skill contract.
4. Swarm profile.
5. Task packet.
6. Memory policy.
7. Tool policy.
8. Handoff packet.
9. Run receipt.
10. Evolution release.
