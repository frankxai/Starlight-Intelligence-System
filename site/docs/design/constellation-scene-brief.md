# Constellation Protocol & Pack Ledger — Scene Brief

## Signature idea

An evidence observatory: the constellation appears not as decorative stars but
as a chain of receipts. Portrait, card, prompt, eval, visual, graph, and pack
states align into one inspectable instrument.

## Composition

- Hero left: a monumental editorial claim, “The constellation, as proof.”
- Hero right: an exact release trust envelope with five shortened digests and
  explicit exclusions.
- Middle: a sparse sequence of trust and packaging ledgers.
- House chapters: five portrait dossiers arranged as a protocol ledger, each
  with four source hashes and the authority it does not hold.
- Closing: three public domains with one canon and a literal SIP attestation.

## Asset route

Tier B generated-owned portraits are compiled from the public .ai projection.
The sync script re-hashes every source WebP before publication. Labels and
status are Tier C HTML/CSS. Generated pseudo-glyphs are never treated as real
interface content.

## Motion

Static composition is authoritative. Only CSS hover/focus state is used.
Reduced-motion removes those transitions. No scroll choreography is required.

## Failure states

- Do not show “install” beside an artifact that has no runtime adapter.
- Do not imply structural eval linkage is live model evaluation.
- Do not expose absolute paths, private memory, secrets, or authenticated
  runtime leases.
- Name the validated local marketplace listing precisely; do not claim installation, runtime admission, entitlement, or commercial availability.
