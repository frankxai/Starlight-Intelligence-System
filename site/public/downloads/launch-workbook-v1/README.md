# Starlight launch workbook · v1.0.0

Turn one useful workflow into a product someone can try, understand and receive.
This is an editable working pack, released free under the included MIT license.
No account, plugin installation or API key is needed. A text editor is enough;
a spreadsheet app is useful for the CSV. Any AI host you choose has its own terms
and costs. These files do not connect accounts, publish pages or take payments.

## Start here

1. Read `worked-example.md`. It is a fictional demonstration, not customer evidence.
2. Copy `offer-brief.md` and write one buyer, one problem and one observable result.
3. Complete `delivery-checklist.md` against your real files and delivery route.
4. Fill `economics.csv` with observed values or clearly marked assumptions.
5. Run the bounded test in `distribution-plan.md` after you authorize publication.
6. Keep your evidence and revise the offer from what people actually do.

## A useful first session

Bring one existing workflow, an example input, its actual output and permission
to use the material. First fill sections 1 and 2 of offer-brief.md, then write
one delivery check with its exact expected output. You should leave with a scoped
offer draft, a delivery test
and one small distribution experiment. This pack cannot establish demand,
profitability, legal suitability or a product's technical capability for you.

Optional prompt for your own AI assistant:

> Use this workbook to help me package one workflow. Ask for missing evidence.
> Keep observed facts separate from assumptions. Draft the offer and a delivery
> test using only assets I own or have permission to distribute. Do not publish,
> connect accounts, buy anything or promise results on my behalf.
