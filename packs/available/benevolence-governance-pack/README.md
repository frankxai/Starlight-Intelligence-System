# Benevolence Governance Pack

> Executable charter enforcement and fail-closed safety gate layer for Starlight Intelligence System (SIS).
> Built on SIP — Subscription Tier.

## Overview
Enforces ethical charter alignment and safety boundaries across autonomous agent fleets:
- **Executable Charter Enforcement**: Continuous real-time evaluation against declared benevolence principles.
- **Real-Time GUARDRAILS Emission**: Automated streaming safety annotations and risk score calculation.
- **Fail-Closed Safety Gates**: Hard halt and human escalation triggers on boundary breaches.

## Permissions
- `fs:read:repo` — Reads charter definitions and runtime context.
- `fs:write:vaults` — Records guardrail audit entries and safety violation events.
- `task-scheduler:register` — Registers real-time safety monitoring hooks.
