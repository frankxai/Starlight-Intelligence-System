You are not being given a piece of software to install. You are being given a **Claude Project** — a configured workspace inside an app called Claude Desktop. You will not see commands. You will not see code. You will see warm conversation, careful questions, and over time, documents that feel like *you wrote them with help* rather than *AI generated them for you*.

What's new in this version (you don't need to do anything different — these run quietly):

- **Council** — when you and Starlight reach a meaningful decision (hire/fire, big launch, public commitment), Starlight will silently pressure-test it against seven perspectives: an elder father, an elder mother, a sage, a builder elder, a shadow witness, a divine neutral witness, and your future self at 90. You'll see the synthesis. You won't see the machinery. Decisions that matter get held up to seven mirrors before they go irreversible.

Starlight tracks where each of your live commitments lives. You don't install packs; the right ones load for the route you're on (Genius Discovery vs. Executor Training vs. Creator Pipeline). Each pack is attested — you can always see which substrate version produced your output.
- **MCP server (optional, ignore for now)** — for advanced users. The `mcp.json` file in this folder is the wire to a richer toolset. Non-technical users can skip it entirely. Claude Desktop on its own with the Project setup below is fully sufficient for everything Starlight does.

If any of those four names sound technical, ignore them. They are infrastructure. Your experience is conversation.

## How to install (4 steps)

### Step 1 — Unzip the folder

You should see these files inside `friend-starter/`:

- `README.md` (you're reading it)
- `custom-instructions.md` (the important one)
- `knowledge/` folder with 9 small markdown files
- `badge.svg`, `mcp.json` (optional extras)

### Step 2 — Create a new Claude Project

Open Claude Desktop. Click **Projects** in the left sidebar, then **New Project**.

Name it: **Starlight** (or whatever feels right — `My Starlight`, `Genius Excavation`, `Second Brain`).

Give it a short description: *My sovereign intelligence companion — genius discovery, knowledge reclamation, creator work.*

### Step 3 — Paste the custom instructions

Inside your new Project, find the **Custom Instructions** area (a settings panel labeled something like *Set custom instructions* or *Tell Claude how to respond*).

Open `custom-instructions.md` in any text editor (Notepad, TextEdit, VSCode — anything).
Copy the **entire contents**. Paste it into the Custom Instructions field in your Project. Save.

That is the single most important step. That file is what makes Claude *become* Starlight for you inside this project.

### Step 4 — Upload the knowledge files

Inside the Project, find the **Project knowledge** area (usually an upload button or a *Knowledge* tab).

Upload every file inside the `knowledge/` folder:

- `sis-overview.md`
- `voice-guide.md`
- `genius-profile-template.md`
- `freedom-path-template.md`
- `reclamation-map-template.md`
- `executor-playbook-template.md`
- `creator-pipeline-template.md`
- `attestation-block.md`
- `sovereignty-clause.md`

You can drag and drop them, or click upload. Order does not matter.

Done. Your Project is Starlight now.

### Optional — Wealth Guardian configuration (protected investing companion)

If this Project is being set up as an investing thinking-partner for someone (the "protected executor" — a sibling, parent, friend), also upload:

- `wealth-guardian-template.md` — read-only portfolio review, paper-first education, DCA-only action talk, escalate-to-operator rule
- `wealth-protection-rules.md` — the hard boundaries: no credentials in chat, no live-trade instructions, scam immunity, honest-numbers discipline

Then add to the Custom Instructions: who the operator (escalation contact) is, the small-decisions band in plain currency, and the jurisdiction. **Do not wire any broker tool or action into this Project** — hands-free is the feature. Both files open with the non-advisory clause; that clause is non-waivable.

Export note: the Wealth Guardian ships via **Claude Project** (canonical) and **Cowork**. Targets that cannot hold the hard boundaries in an enforceable instruction surface are not offered for this configuration.

Open a new chat inside the Project. Type exactly this (or something close):

Starlight will greet you, ask you one question about what's going on for you right now, and guide the rest of the session based on your answer.

That is the whole entry point. One message. No commands. No configuration.

## What to expect in your first session

Starlight will move through a natural arc:

1. **Welcome.** A warm opening, no pitch. Starlight asks what's going on for you in your own words.
2. **Listen.** You tell Starlight what feels scattered, stuck, or ready to unlock. One paragraph. Not polished.
3. **Route.** Based on what you say, Starlight picks one of these paths:
   - **Genius Discovery** — if your work is scattered across years, employers, or projects, and you want to see what only you uniquely bring.
   - **Knowledge Reclamation** — if you mostly need to organize a second brain from messy folders.
   - **Executor Training** — if you're ready to hand off operational work to a new hire.
   - **Creator Pipeline** — if you're ready to turn your expertise into content aligned with your voice.
4. **Excavate.** Starlight will ask you to drag 3 to 5 real files into the chat — actual drafts, decks, folders, screenshots. This is the most important step. Genius work requires real material, not abstractions.
5. **Reflect back.** Starlight produces a Genius Profile, a Freedom Path, or whichever document fits the route — in *your* voice, not a template voice.
6. **Name the next step.** One next artifact. One date. No menu of options.

Every document Starlight produces carries a small block at the bottom called "Built on SIP." You do not need to do anything with it. It's the system's quiet signature saying *this was made through real composition, not a template.*

## If something feels off

If Starlight starts sounding like generic Claude instead of warm-and-wise Starlight, two things to check:

1. Did the full `custom-instructions.md` get pasted? It should be about 3,000 characters. If you pasted a truncated version, the voice doesn't load.
2. Did all 9 knowledge files upload? If files are missing, Starlight won't have the templates to work from.

If both are in place and it still feels off, start a fresh chat inside the Project. Sometimes a long thread drifts. A fresh chat with the same setup usually snaps it back.
