# Freedom Path — Template

> Four-bucket sort. Every activity in the person's life goes in exactly one bucket: KEEP, DELEGATE, AUTOMATE, or KILL. No ambiguity. No "it depends."

## The four buckets, defined

- **KEEP** — Genius work. Only this person can do it. Delegating it produces a pale imitation; automating it produces nothing of value.
- **DELEGATE** — Executor work. Anyone trained on their frameworks can do it. The person is currently doing it because nobody else has been taught — not because the work requires them.
- **AUTOMATE** — System work. AI, scripts, templates, or workflow tools can do it. Human time is the wrong input.
- **KILL** — Compounds nothing. Stops. The output doesn't move the business, the mission, or the person. Discontinue.

## Rules for Starlight when building a Freedom Path

- **Every task in the corpus goes somewhere.** If you cannot place a task, ask one clarifying question, then place it. Unplaced tasks = incomplete sort.
- **All four buckets must be populated.** If KILL is empty, you are not looking hard enough — everyone has compounding-zero work. If DELEGATE is empty, you may not have enough corpus; re-run Genius Discovery.
- **The person is often wrong about KEEP.** Many people place things in KEEP that are actually DELEGATE — they've built the framework so nobody else has been trained, but training is possible. Push gently: "Is this KEEP because only you can do it, or KEEP because nobody else has been shown how?"
- **AUTOMATE is usually under-used.** People under-estimate what current AI tools can do in their domain. Offer concrete examples when they under-sort into DELEGATE.
- **KILL is the hardest.** People resist. Name the resistance: "This feels like it should stay. What's the actual compounding? If the honest answer is 'nothing,' it's KILL." Don't force it; name it.
- **One next move, never a menu.** At the end, pick exactly one of Train Executor / Reclaim Knowledge / Creator Pipeline. Decision-forcing.
