# Infographic & System Prompts — Starlight Intelligence

**Important**: For anything with exact text, labels, data, structure, or math — prefer **code-built** (React/SVG/HTML + Tailwind or clean SVG) over pure image_gen per imagine skill best practices. Image_gen excels for mood, atmosphere, artistic plates, Queen+swarm compositions. Use generated bases as beautiful backgrounds or illustrative elements behind precise code layers.

**When to use image_gen/edit for infographics**:
- Atmospheric full-bleed plates (Queen overseeing hierarchy, glowing orb systems).
- Stylized non-text-heavy diagrams where mood > exact labels.
- Social infographic variants.

**Palette & DNA**: Always #060609 + accents. Glass, luminous particles, neural connections. Sovereign Queen central only where appropriate; chibi for agent nodes.
