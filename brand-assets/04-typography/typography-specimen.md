# Starlight Intelligence — Typography Specimen (Premium 2026)

**World-class pairing for sovereign cosmic intelligence brand.**

## Recommended Stack (only the best)

**Headings / Display**
- Font: Fraunces (variable, elegant with soft serifs) or Playfair Display / EB Garamond
- Weights: 600–700
- Sizes: 48–96px
- Letter-spacing: -0.02 to -0.04em
- Example: "The Queen conducts the swarm"

**Body / UI**
- Font: Inter (or Satoshi / Neue Haas Grotesk for ultimate premium)
- Weights: 400–600
- Sizes: 16–20px
- Line-height: 1.65–1.75
- Example: Persistent context and memory architecture for AI agents. Built on the Starlight Intelligence Protocol.

**Accent / Cosmic**
- Font: Space Grotesk or Cabinet Grotesk
- Weights: 500–600
- For labels, swarm names, taglines.

**Mono / Technical**
- Font: JetBrains Mono or Berkeley Mono
- For code, SIP specs, data.

## Pairing Rule
Always: Elegant serif (Fraunces) for authority + clean sans (Inter/Satoshi) for clarity + geometric display for magic.

Never mix more than 3 typefaces.

## 2026 Premium Notes
- Variable fonts preferred for fluid scaling.
- Optical sizing on serifs for large display use.
- Generous tracking on small caps/labels for cosmic feel.
- High contrast for accessibility on deep void backgrounds.
