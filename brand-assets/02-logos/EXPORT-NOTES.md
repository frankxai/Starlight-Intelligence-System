# Logo Export Notes for Higher Quality Raster (PNG/JPG)

**Why SVGs first?**
- Vector = infinitely scalable, perfectly crisp at any size (16px favicon to 4000px billboard).
- Tiny file sizes.
- Editable in Illustrator/Figma.
- Future-proof.

**When to use PNG/JPG:**
- Social media uploads (platforms compress, need high-res source).
- Web heroes where you want exact 3D render look.
- Presentations, PDFs, where vector support is spotty.
- Merch (need high-res for print).

**Recommended exports from these SVGs (do this in Figma/Illustrator or online converter):**
- Primary logo: PNG @ 2x and 3x (e.g. 1200px, 2400px width), transparent BG + white BG version.
- Icon: PNG 512x512, 1024x1024, 2048x2048 (for app icons, favicons).
- Monochrome: same sizes, for dark/light modes.

**Using with existing 3D renders:**
- For "Queen + logo" lockups: composite the SVG icon over the best queen-premium JPGs (e.g. 67.jpg, 71.jpg, 78.jpg) at high quality.
- Export final composites as JPG/PNG at 300dpi for print, sRGB for web.

**Best practice 2026:** Always start with SVG master. Generate raster from it + layer on premium 3D illustrations only when the design requires the specific render quality.
