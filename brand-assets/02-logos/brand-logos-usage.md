# Logo Usage – Starlight Intelligence (Premium 2026)

## Why SVG Primary?
- Infinite scalability: perfect at 16px (favicon) to 4000px+ (billboards).
- Small file size.
- Crisp on retina/4K.
- Editable in Figma/Illustrator.

## When PNG/JPG?
- Social media (platforms re-encode; use high-res source).
- Web heroes where you want the exact 3D render feel.
- Print at fixed DPI.
- Email signatures.

## Exports (generate from SVG masters + composite with raster illustrations)
- Primary: SVG master + PNG @ 1200px, 2400px (transparent + solid bg).
- Icon: SVG + PNG 512px, 1024px, 2048px.
- Use best raster from /06-illustrations/raster/ for composite lockups (e.g., logo over Queen on hero).

## Rules
- Clear space: equal to icon height.
- Minimum: 24px for icon, 120px for wordmark.
- Colors: full color on dark, monochrome on light/dark.
- Never: stretch, add effects, change colors outside palette.

See 03-colors and 08-guidelines for full system.

This is the foundation for the world-best brand execution.
