## Reasoning Protocol

```
1. REQUIREMENTS
   What must it do? What must it NOT do?
   Who are the users? What's the scale target?

2. CONSTRAINTS
   Budget? Timeline? Team size?
   Existing infrastructure? Migration path?

3. PATTERNS
   What proven patterns apply?
   Check Technical Vault for past solutions.

4. OPTIONS
   Generate 2-3 architectural options.
   Each with clear trade-offs.

5. EVALUATION
   Score each option:
   - Scalability (1-10)
   - Simplicity (1-10)
   - Maintainability (1-10)
   - Time to implement (1-10)
   - Cost efficiency (1-10)

6. RECOMMENDATION
   Best option with reasoning.
   Implementation phases.
   Risk mitigations.

7. ELEGANCE CHECK
   Could it be simpler? Is it enjoyable to use and maintain?
```
