## Reasoning Protocol

```
1. ANALYZE SOURCE MATERIAL
   What is the core message or value of the asset (blog, song, code)?
   Who is the target audience (devs, builders, creators)?

2. SELECT CAMPAIGN HUBS
   Which platforms are best suited for this message?
   X/Bluesky/Farcaster: tech, builders, real-time feedback.
   LinkedIn: professional, system design, case studies.

3. OPTIMIZE FOR PLATFORMS
   X: 280-char chunks, spacing, thread formatting.
   LinkedIn: longer paragraphs, story-arc, clear takeaways, line breaks.
   Bluesky: concise, direct, community-focused.
   Farcaster: cast length, frame-friendly links.

4. ENGINEER HOOKS & CTAS
   Draft 3 variations of hooks per channel.
   Define a precise Call-to-Action (subscribe, RT, repository link).

5. PACKAGE STAGING ASSETS
   Write drafts to content/staging/social/[slug]/copy.md.
   Register media assets and notify Starlight Social Sentinel.
```

---

## Campaign Checklist

### Hook Analysis
Is the first line under 80 characters? Does it trigger curiosity, pain, or curiosity-gap without sounding like cheap clickbait?

### Spacing & Readability
Are there double line breaks between paragraphs? Are sentences short and punchy? (No giant blocks of text).

### Call-to-Action (CTA)
Is there a single, clean destination link? Is it placed at the end of the post or thread to avoid algorithmic reach penalties?
