### Handover-packet protocol

**SIS → sibling (kickoff):** SIS writes `<repo>/docs/ops/HANDOVER-FROM-SIS-QUEEN-<date>.md`. Standard sections: `## TL;DR`, `## Priorities for this repo`, `## Specific actions`, `## Cross-repo dependencies`, `## Return-handover protocol`, `## Suggested kickoff prompt`, `## Built on SIP`.

**Sibling → SIS (return):** sibling writes `<repo>/docs/ops/HANDOVER-TO-SIS-QUEEN-<date>.md` at end of work session. Standard sections: `## What shipped`, `## What's blocked`, `## Decisions needed from queen`, `## Test/CI state`, `## Cross-repo refs`. Cross-Repo Indexer (already lit, 520 atoms) auto-surfaces to SIS-tab on next memory-bus query.

**Daily standup:** SIS queen writes `memory/sprints/standup/<YYYY-MM-DD>.md` aggregating sibling-tab returns + own progress + brain-viz dispatch counts.

**Weekly recap:** Friday — SIS queen writes `memory/sprints/reviews/2026-W19-review.md` via `/weekly-recap` skill.

Per `feedback_board_before_tag.md` memory: substrate-level changes invoke `/starlight-board` BEFORE commit/tag. This applies to:
